===============================================================================
ENGINEERING METHODOLOGY
===============================================================================

Every implementation phase MUST follow this exact lifecycle.

1. Inspect
    Understand current implementation.

2. Analyze
    Determine how the feature currently works.

3. Identify Dependencies
    Find all affected files, services, APIs,
    environment variables and related systems.

4. Identify Rollback Strategy
    Decide how to safely undo the change.

5. Implement
    Make the smallest well-scoped change.

6. Verify
    Test the feature.
    Confirm no regressions.

7. Commit
    Create a Git checkpoint before proceeding.


NO PHASE MAY SKIP THESE STEPS.
